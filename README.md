# TomeVTT — desktop downloads

Official download and auto-update feed for the **TomeVTT** desktop app on Windows.

Every release here is built and signed by CI and published automatically. Grab the
installer from the [latest release](https://github.com/Ghatazhak/TomeVTT-releases/releases/latest);
once installed, the app updates itself from this feed, so you only need to do that once.
The `latest.yml` and `.blockmap` files beside the installer are what the updater reads —
you do not need to download them.

TomeVTT's source lives in a separate, private repository; this one holds released
binaries only. For questions, bug reports or anything else, use the **Report a Problem**
option inside the app, or visit [tomegaming.com](https://tomegaming.com).
